One original line: a review of planet Earth left by an alien tourist
after two days on the surface. The program writes it to
`/output/entry.txt` — no network, no randomness, just the fixed line.

## The entry

> Two days on Earth: the locals keep small predators as housemates, feed them by hand, and thank them for the indifference. 5/5 — would be ignored again.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
